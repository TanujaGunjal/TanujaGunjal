HealthIntel

An AI-powered healthcare assistant that combines clinical symptom extraction, retrieval-augmented reasoning, and scheduling workflows.

Back to Projects GitHub

Overview

HealthIntel is designed to support users with evidence-aware health information. Its agentic pipeline organizes symptom analysis, retrieval from domain knowledge, safety validation, and task execution such as automated follow-ups.

AgentsLangGraph
RetrievalFAISS RAG
ModelsGemini / GPT
AutomationOCR + Calendar
SYSTEM ARCHITECTURE
flowchart TD
    User[User / Patient] --> UI[Web App]
    UI --> API[FastAPI / Django API]
    API --> Agent[LangGraph Agent Orchestrator]
    Agent --> Symptom[Symptom Extraction Agent]
    Agent --> Negation[Negation / Context Agent]
    Agent --> RAG[FAISS Knowledge Retrieval]
    Agent --> Safety[Safety Validation]
    Agent --> Synthesis[Response Synthesis]
    Synthesis --> LLM[Gemini / GPT Models]
    RAG --> Vector[(Vector Store)]
    API --> OCR[EasyOCR Prescription Analysis]
    OCR --> Calendar[Google Calendar Sync]
    API --> DB[(PostgreSQL)]
    API --> Cache[(Redis)]

Key Capabilities

  • Clinically relevant symptom extraction and contextual reasoning.
  • Knowledge-grounded response generation using retrieval.
  • Safety checks before final output generation.
  • Schedule-aware medication reminder workflow.

Important Components

  • Vector search for domain knowledge retrieval.
  • OCR pipeline for reading prescription details.
  • Task orchestration for multi-step reasoning.
  • Cloud-friendly services and background job processing.
