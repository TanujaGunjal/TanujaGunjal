HireLens

An AI-powered resume and interview platform that helps candidates improve ATS compatibility and interview readiness.

Back to Projects GitHub

Overview

HireLens combines resume analysis, AI guidance, and mock interview preparation into a single workflow. It helps users understand how well their profile aligns with a job description and what improvements should be made.

FrontendReact + Vite
BackendExpress.js
StoreMongoDB
AIGemini API
SYSTEM ARCHITECTURE
flowchart LR
    User[Candidate] --> Frontend[React Frontend]
    Frontend --> API[Express API]
    API --> Auth[Auth / Session Layer]
    API --> Resume[Resume Analysis Service]
    Resume --> Matcher[ATS + Keyword Matching]
    Resume --> AI[AI Resume Optimization]
    AI --> Gemini[Google Gemini API]
    API --> Interview[Mock Interview Engine]
    API --> DB[(MongoDB)]
    API --> Redis[(Redis Cache)]
    Admin[Admin Dashboard] --> API

Product Flow

  • Resume upload and parsing for ATS-related analysis.
  • Semantic and keyword-based similarity checks against job descriptions.
  • AI-powered rewrite and improvement suggestions.
  • Mock interview generation based on resume and target roles.

Operational Design

  • Redis caching reduces repeated query and AI generation overhead.
  • MongoDB stores user profiles, resume data, and platform analytics.
  • Admin flows support monitoring and content management.
